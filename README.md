# Student Record Management System

## Description

A beginner-friendly Python project that manages student records using CRUD operations and CSV file handling.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- CSV file storage
- Exception handling

## Technologies Used

- Python
- CSV
- File Handling
- Exception Handling
- Functions

## CRUD Operations

Create - Add student records

Read - View and search student records

Update - Modify student records

Delete - Remove student records

## How to Run

Run the following command:

python student_records.py
